# 招聘 JD 采集分析 Agent

一个可本地运行的对话式 Agent：你说一句需求，它去**智联招聘 / 猎聘**采集岗位 JD，
清洗归一后生成详细的市场数据分析（薪资分布、门槛结构、技能溢价、招聘集中度、人岗匹配等），
并支持追问式深挖和一键导出报告。

**零第三方依赖**：Python 3.10+ 标准库即可运行，前端为原生 HTML/CSS/JS，离线可用。

## 快速开始

```bash
python run.py        # 默认 8770 端口
# 打开 http://127.0.0.1:8770
```

然后直接对话，例如：

- `帮我搜集杭州数据分析师的岗位，月薪 15K 以上，3 年经验`
- `深圳有哪些大模型算法工程师岗位，越多越好`
- `我会 Python、SQL，4 年经验，本科，期望 25K`（记住画像后自动算匹配度）
- `只看本科，薪资最高的前 10` / `那硕士学历的呢`（在上一轮结果上追问）
- `这些岗位我最缺什么技能` / `导出报告`

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 自然语言解析 | 抽取岗位词、城市、薪资区间、经验、学历、数据源、排除词；支持口语（“帮我”“看看”“越多越好”） |
| 关键词扩展 | 单关键词在智联只返回 20 条，自动扩展近义词（数据分析师 → 数据分析 / 商业分析）扩大样本 |
| 采集清洗 | 标题+公司+链接三级去重；薪资文本 → 月薪区间（支持 ·13薪、年薪、日薪折算）；经验/学历/公司规模归一 |
| JD 补全 | 列表页正文被截断到 ~70 字，自动并发抓详情页全文，技能识别准确率显著提升 |
| 技能抽取 | 内置 130+ 技能词典（AI/大模型/数据/云/测试/产品…），平台标签 + JD 正文双通道，含别名归一 |
| 分析引擎 | 分位数（P10–P90）、分布直方、城市/经验/学历/规模/行业交叉中位数、技能词频与**薪资溢价**、技能共现、招聘集中度、数据质量体检、自动文字洞察 |
| 人岗匹配 | 技能 50% + 薪资 20% + 经验 18% + 学历 12% 加权评分，输出 Top 匹配、命中/缺失技能、技能缺口榜、各维度得分 |
| 追问多轮 | 「只看硕士」「薪资前10」「城市对比」「缺什么技能」等在既有结果上筛选/重算，不重复采集 |
| 导出 | 独立 HTML 报告（含全部图表，可直接分享）+ CSV 明细；明细页也可直接下载 CSV |
| 降级策略 | 某关键词无结果自动换降级词重试；某数据源失败自动跳过并提示原因 |

## 数据源说明（重要）

### 智联招聘 ✅ 开箱即用
走 `sou.zhaopin.com` 服务端渲染页内嵌的 `__INITIAL_STATE__` 数据通道，无需登录。
限制：每个关键词仅返回第一页 20 条（服务端忽略翻页参数），已用关键词扩展弥补。

**城市码**：`jobagent/data/zp_cities.json`（396 个城市），不是手抄的——用「搜索页 `<title>` 反查城市」
逐个校验生成。老版本手写表有 20 处错位（例如 702 是济南不是青岛、703 是青岛不是烟台），
导致「搜青岛返回一堆济南岗位」。现在除了按码检索，还会按 `city` 字段二次过滤，剔除外地结果并给出提示。
未收录的城市回退全国检索 + 本地过滤，同样会提示。

### 猎聘 ✅ 开箱即用（浏览器渲染通道）
搜索页是纯客户端渲染（React SPA），数据接口 `api-c.liepin.com` 需要 `x-fscp-std-info` 签名头，
匿名直连一律返回 `{"code":"-1400"}`，因此不走接口逆向，改用 **headless Chrome/Edge 渲染**拿最终 DOM：

- 无需登录：列表 40 条/页、字段齐全（薪资含 `·15薪`、城市区、经验、学历、公司、行业、融资阶段、规模、招聘者）
- 翻页：`currentPage=0,1...`；城市必须用 `dq=<编码>`（`city=` 参数会被忽略）
- 详情页 JD 全文在 `[data-selector="job-intro-content"]`
- **风控注意**：UA 带 `HeadlessChrome` 或高频访问会弹「行为异常」验证码墙（实测约 2 分钟后自动解除）。
  适配器已内置真实 UA、串行渲染 + 2.5s 最小间隔、翻页上限 2 页、详情补全上限 8 条
- 依赖：本机需装有 Chrome 或 Edge（自动探测，也可用环境变量 `CHROME_PATH` 指定）
- 城市编码仅收录页面筛选器里能取到的热门城市（含济南 250020 / 青岛 250070），其余城市自动退化为全国检索后本地过滤

## 目录结构

```
jobagent/
├── agent.py          # Agent 编排：意图识别 → 检索计划 → 采集 → 分析 → 回答
├── nlu.py            # 自然语言解析 + 关键词扩展
├── analyzer.py       # 分析引擎（分布/交叉/溢价/共现/匹配/洞察）
├── normalize.py      # 薪资/经验/学历/规模归一化
├── skills.py         # 技能词典与抽取
├── report.py         # 独立 HTML 报告渲染
├── store.py          # 会话持久化（JSON）+ CSV 导出
├── server.py         # 零依赖 HTTP 服务 + JSON API
└── adapters/
    ├── zhaopin.py    # 智联适配器（直连可用）
    ├── liepin.py     # 猎聘适配器（headless 浏览器渲染，无需登录）
    └── htmlimport.py # 页面 HTML / JSON 导入解析
web/                  # 前端（原生 JS，无框架）
data/                 # 会话与导出文件（自动生成）
run.py                # 启动入口
```

## HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/chat` | `{sid, message}` → 回复 + 分析 + 岗位 |
| POST | `/api/import` | `{sid, text, hint}` → 解析导入内容并分析 |
| POST | `/api/settings` | 保存 Cookie / 详情补全开关 |
| GET | `/api/session?sid=` | 恢复会话（支持 `?sid=&tab=` 直达分享） |
| GET | `/api/report?sid=` | 独立 HTML 报告 |

## 合规与边界

- 仅采集公开搜索结果页用于个人求职决策研究，请控制频率（内置随机 0.8–2s 间隔）。
- 请遵守目标网站的服务条款与 robots 协议，勿用于商业转售或大规模抓取。
- 薪资数据为招聘方自报区间，分析结论仅供决策参考。
